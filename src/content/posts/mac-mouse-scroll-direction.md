## 為什麼 Mac 的滑鼠滾輪方向是反的

macOS 預設開啟「自然捲動」（Natural scrolling）：手指往上滑，頁面內容跟著往上移動，像在觸控螢幕上推動紙張。這個方向在觸控式軌跡板上很直覺，但接上一般滑鼠後，滾輪往下轉，頁面卻往上跑，和 Windows 的習慣相反。

如果你只用滑鼠，到系統設定把它關掉就好。如果你同時使用 MacBook 的觸控式軌跡板和外接滑鼠，事情就比較麻煩，因為兩者在系統裡共用同一個開關。

## 方法一：在系統設定關閉自然捲動

只用滑鼠，或滑鼠和軌跡板都想改回傳統方向，用這個方法就好。

1. 開啟「系統設定」。
2. 在側邊欄選擇「滑鼠」。
3. 關閉「自然捲動」。

設定會立即生效，不需要重新開機。若側邊欄找不到「滑鼠」，表示系統目前沒有偵測到滑鼠；先確認藍牙或接收器已連線。

:::note
在「滑鼠」關閉自然捲動後，「觸控式軌跡板」→「捲動與縮放」裡的「自然捲動」也會一起關閉，反之亦然。macOS 目前沒有內建選項可以分開設定兩者。
:::

### 用終端機修改

這個設定對應的是全域偏好設定 `com.apple.swipescrolldirection`，也可以用指令修改：

```bash
# 關閉自然捲動
defaults write -g com.apple.swipescrolldirection -bool false

# 恢復自然捲動
defaults write -g com.apple.swipescrolldirection -bool true
```

用指令修改後，通常需要登出再登入才會完全生效。它改的仍是同一個共用設定，無法只影響滑鼠，所以直接用系統設定就好。

## 方法二：滑鼠與軌跡板分開設定捲動方向

如果想要「軌跡板維持自然捲動、滑鼠使用傳統方向」，需要第三方工具。這類工具的做法是讓系統保持自然捲動，再攔截滑鼠滾輪事件，把方向反轉回來。

| 工具                                                     | 特色                                             | 適合情境                      |
| -------------------------------------------------------- | ------------------------------------------------ | ----------------------------- |
| [LinearMouse](https://linearmouse.app/)                  | 開源；可依裝置分別設定捲動方向、指標速度與加速度 | 想一併調整滑鼠手感            |
| [Mos](https://mos.caldis.me/)                            | 開源；提供平滑捲動，可分別反轉滑鼠方向           | 覺得 Mac 上滑鼠滾輪捲動不夠順 |
| [Scroll Reverser](https://pilotmoon.com/scrollreverser/) | 功能單純，只處理捲動方向                         | 只想解決方向問題              |

選一個使用即可，**不要同時開啟多個**。它們都會處理滾輪事件，同時執行可能互相抵銷，讓方向變回原本的樣子。

### 使用前先把系統設定還原

這類工具通常假設系統的「自然捲動」是開啟的。如果你先前已經依照方法一關閉它，請先到「系統設定」→「滑鼠」或「觸控式軌跡板」重新開啟，否則結果會剛好相反：滑鼠被反轉回自然捲動，軌跡板則維持傳統方向。

### 以 LinearMouse 為例

1. 從官網下載，或使用 Homebrew 安裝：

   ```bash
   brew install --cask linearmouse
   ```

2. 開啟 LinearMouse，依提示到「系統設定」→「隱私權與安全性」→「輔助使用」允許 LinearMouse。
3. 在 LinearMouse 視窗上方選擇你的滑鼠裝置。
4. 在「Scrolling」頁面開啟「Reverse scrolling」。
5. 開啟「Start at login」，讓它在登入時自動執行。

完成後，滑鼠滾輪會變成傳統方向，觸控式軌跡板則維持自然捲動。

### 使用 Mos 或 Scroll Reverser

兩者的流程類似：

- **Mos**：`brew install --cask mos`，開啟後允許「輔助使用」權限，在偏好設定中開啟滑鼠的「反轉」，並確認不會套用到觸控式軌跡板。
- **Scroll Reverser**：`brew install --cask scroll-reverser`，允許權限後勾選「Reverse Scrolling」，再只勾選「Reverse Mouse」，取消「Reverse Trackpad」。

各工具的選項名稱可能隨版本調整，以實際介面為準。

## 疑難排解

### 設定後方向沒有改變

確認工具已取得「輔助使用」權限。若權限已勾選仍無效，在權限清單中移除該 App 後重新加入，再重新啟動工具。

### 軌跡板方向也被反轉了

檢查工具是否只套用到滑鼠，並確認系統的「自然捲動」是開啟狀態。同時確認沒有其他滑鼠工具（例如 Logi Options+）也在處理捲動方向。

### 羅技滑鼠用 Logi Options+ 可以設定嗎？

支援的羅技滑鼠可以直接在 Logi Options+ 調整捲動方向。如果你只用羅技滑鼠，先試這個內建選項，就不必另外裝工具。

### 想恢復原本的行為

結束並移除第三方工具，再到「系統設定」→「滑鼠」確認「自然捲動」的狀態即可。

## 快速對照

- 只用滑鼠：到「系統設定」→「滑鼠」關閉「自然捲動」。
- 滑鼠與軌跡板都用：保留系統的自然捲動，再用 LinearMouse、Mos 或 Scroll Reverser 只反轉滑鼠。
- 第三方工具擇一使用，並記得允許「輔助使用」權限。
